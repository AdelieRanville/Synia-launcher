What the launcher does

Synia shows information from Wikidata in ready-made views. Each view is described on a Wikidata page, called an aspect page. For example, an aspect page can list the works linked to a person, or the venues of a city.

The launcher helps you pick an aspect page, tell it which Wikidata item or items you are interested in, and open the result in Synia. You no longer need to build the Synia address by hand.

Open a page in three steps

  1. Choose an aspect page

    You have three ways to do it:

    • Paste its address from Wikidata into the first field.
    • Pick a recent one. Click in the field and the pages you used before are suggested.
    • Browse the list. Click “Browse aspect pages”, type a few letters to filter, and click the page you want.

  2. Add the item or items

    The launcher shows the right number of fields for the page you chose. Start typing a name in a field, for example the name of a person, a city or a language, and pick the match from the suggestions. If you already know the Wikidata number (such as Q42), you can type it directly.

    The last field is always optional. See How many items do I need? below.

  3. Click “Open in Synia”

    Synia opens in a new tab. The address is also shown under the button, in case your browser blocked the new tab.

How many items do I need?

The launcher works it out for you from the name of the aspect page. You do not have to remember anything, but it helps to know what to expect:

If the page name…The launcher asks forExample
ends with -indexNo itemlibrary-index
has no dashOne itemvenue
has a dash joining two namesTwo items, in the order of the nameslanguage-language

Leaving the last field empty is fine. Synia may then show a more general page, such as an overview, instead of a page about one specific item. With two items, the first one is needed; the second is optional.

When the two names in the page name are the same, as in language-language, the fields are labelled “first” and “second”. The order can matter, so check which item you put where.

Handy tips

Share exactly what you see

You can send colleagues a link that already contains the aspect page and the items, so they only have to click “Open in Synia”. Add the details to the end of the launcher address like this:

synia-launcher.html?aspect=Wikidata:Synia:language-language&item1=Q9035&item2=Q150

Use item1 for the first item and item2 for the second. If you only want to share the aspect page, leave the items out.

Find out what an aspect page contains

In the browse list, the small arrow next to each page opens it on Wikidata, so you can read its title and queries before using it.

Redirects

Some entries in the list are marked redirect. They simply point to another page, and you can use them like any other.

Change the item, keep the page

Come back to the launcher, change the item, and click the button again. Your aspect page is only a click away in the recent suggestions.

Create your own aspect page

If you can edit Wikidata, you can write your own aspect page. Create a new subpage of Wikidata:Synia, for example Wikidata:Synia:myaspect, and add a title and your queries. Then paste its address into the launcher.

Choose the page name carefully. The name tells the launcher how many items to ask for (see the table above). Use no dash for one item, two names joined by a dash for two items, and end the name with -index for a page that needs no item. Capital letters matter: -Index is not the same as -index.

If something goes wrong

The launcher says the address is not valid

Paste the full address of the Wikidata page, starting with https://www.wikidata.org/. Addresses from other websites are not accepted.

No item field appears

Either the page needs no item (its name ends with -index, and the launcher says so), or the address is not valid yet. Check for a red message under the first field.

I cannot find my item in the suggestions

Try another spelling, a shorter search, or the name in another language. If you know the Wikidata number, type it directly, for example Q42.

The launcher asks me to choose a suggestion

It means you typed a name without picking one of the matches. Click a suggestion in the list, type a Wikidata number, or clear the field if the item is optional.

Nothing opens when I click the button

Your browser may have blocked the new tab. Use the link shown under the button, or allow pop-ups for this site.

The list of aspect pages does not load

Check your internet connection and click “Refresh list”. You can still paste an address in the meantime.

The page I opened in Synia is empty or not what I expected

Check that you picked the right item, and in the right order for pages with two items. Opening the aspect page on Wikidata, with the small arrow in the list, shows what it is meant to display.
